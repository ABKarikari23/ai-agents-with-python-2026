## What this covers

This part focuses on task automation. Instead of only answering questions, agents can take a job, break it into steps, execute actions, and check the results before handing the workflow back to a human when needed.

## Setup

```bash
python -m venv venv
source venv/bin/activate   # on Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Notes

The workflow demonstrates the core agentic automation pattern: interpret the task, plan the steps, act, and validate the outcome.
