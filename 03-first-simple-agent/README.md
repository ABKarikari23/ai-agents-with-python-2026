## What this covers

This part builds a minimal, rule-based agent that responds to user input, keeps track of prior messages, and demonstrates the basic pattern behind a working conversational agent.

## Setup

```bash
python -m venv venv
source venv/bin/activate   # on Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Notes

This is a friendly introduction to agent design. It avoids external dependencies so you can focus on the behavior and flow of the agent itself.
