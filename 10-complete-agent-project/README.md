## What this covers

This final part puts everything together into a practical agent project: task planning, tool use, memory, safety checks, and a simple end-to-end workflow that behaves like a real assistant.

## Setup

```bash
python -m venv venv
source venv/bin/activate   # on Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Notes

This project is intentionally simple and educational. It demonstrates the architecture of a complete agent without locking you into a specific framework or cloud platform.
