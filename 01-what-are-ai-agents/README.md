## What this covers

This part introduces the difference between a chatbot and a true AI agent. You will see how agents combine a goal, a reasoning loop, tools, and decision-making to complete tasks instead of simply responding with text.

## Setup

```bash
python -m venv venv
source venv/bin/activate   # on Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Notes

This example is intentionally dependency-light so you can run it immediately. The goal is to understand the core idea of agents before adding external APIs and more advanced patterns.
