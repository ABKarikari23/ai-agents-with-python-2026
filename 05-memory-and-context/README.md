## What this covers

This part focuses on memory and context: how an agent can preserve user preferences, track past steps, and use recent history so conversations and tasks feel coherent.

## Setup

```bash
python -m venv venv
source venv/bin/activate   # on Windows: venv\Scripts\activate

```

## Run

```bash
python main.py
```

## Notes

In real systems, memory is often a combination of short-term session state and longer-term retrieval. This example demonstrates the basic principles in a compact form.
