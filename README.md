# AI Agents with Python 2026
### From Automation to Autonomous Systems

This is the code repository for the **AI Agents with Python 2026** series — a Wednesday series exploring how to design and build AI agents in Python, from first principles to a complete agent project.

It's the continuation of the earlier **AI With Python 2026** series, which covered AI foundations, NumPy, Pandas, Matplotlib, Machine Learning, and AI APIs.

Each folder below corresponds to one article in the series. Every folder is self-contained: its own `README.md`, `requirements.txt`, and starter code, so you can clone the repo and jump straight to the part you're reading.

## How to use this repo

Clone it:

```bash
git clone https://github.com/<ABKarikari23>/ai-agents-with-python-2026.git
cd ai-agents-with-python-2026
```

Then move into whichever part you're following, set up its virtual environment, and run it — instructions are in each part's own `README.md`.

```bash
cd 01-what-are-ai-agents
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Who this is for

Python developers, AI beginners, students, and anyone curious about building practical, tool-using AI applications. Basic Python knowledge is assumed; if you're brand new, the earlier **AI With Python 2026** series is a good starting point.

## A note on responsible AI

Agents in this series are built with guardrails in mind — permissions, authentication, error handling, and human oversight are covered explicitly in Part 9, but the principle applies throughout: more autonomy requires more responsibility.
