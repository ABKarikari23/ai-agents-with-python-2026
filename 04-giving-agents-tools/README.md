## What this covers

This part teaches you how to give an agent tools such as function calls, local utilities, and external service wrappers so it can perform actions beyond producing text.

## Setup

```bash
python -m venv venv
source venv/bin/activate   # on Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Notes

The example uses local tool functions instead of live APIs, which makes it easy to understand the pattern before connecting to real services or model providers.
